# SpendWise Budget Tracker

SpendWise is a Personal Budget and Expense Tracker built using HTML, CSS, and JavaScript.

The application allows users to enter their total budget and expenses. JavaScript processes the information and calculates the remaining balance.

## Project Files

- `index.html` - Creates the structure of the SpendWise application.
- `style.css` - Provides the design, layout, colors, and responsive styling.
- `script.js` - Handles user input, calculations, functions, variables, and console output.
- `README.md` - Explains the project and JavaScript concepts used.

## JavaScript Concepts

The project demonstrates:

- Variables
- Data types
- User input
- Number conversion
- Functions
- Function parameters
- Return values
- Calculations
- Conditional statements
- DOM manipulation
- Event listeners
